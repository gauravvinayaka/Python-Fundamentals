\# Python Fundamentals

This repository contains my Python notes, examples, practice assignments, and solutions as I work through the fundamentals of Python programming.


\## About This Repository
I created this repository to keep my Python learning organized in one place and to track my progress as I practice different concepts.

Most of the material is organized in Jupyter Notebooks so I can combine explanations, code examples, outputs, assignments, and solutions in the same file.


\## Topics Covered
The repository covers core Python concepts along with practice exercises, including:

\- Python syntax and basic programming concepts
\- Variables and data types
\- Strings and collections
\- Operators and expressions
\- Conditional statements
\- Loops
\- Functions
\- Object-Oriented Programming
\- Classes, objects, inheritance, and polymorphism
\- Modules and packages
\- Errors and exception handling
\- Useful built-in functions
\- Decorators
\- Generators


\## Assignments
The notebooks also include assignments for practicing the concepts covered in each section.

Solutions are included at the bottom of the relevant notebooks so I can attempt the problems first and then compare my approach.


\## Repository Format
The repository mainly contains:

\- Jupyter Notebooks (`.ipynb`)

\- Personal notes and explanations
\- Practice assignments
\- Assignment solutions
\- Supporting files where needed
